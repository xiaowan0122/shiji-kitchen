# 食记 Kitchen 数据备份与恢复

核对日期：2026-11-20

# 1. 目标

- 防误删、防换机丢数据、防恶意删除。
- 提供用户可触达的“导出备份 + 导入恢复”。
- 云端为主数据源，本地缓存仅是视图。

# 2. 多层备份策略

| 层级 | 说明 | 自动化程度 |
| --- | --- | --- |
| 云端主数据 | 数据库即为权威数据，天然多副本 | 平台托管 |
| 软删除回收站 | 业务软删除保留期，可恢复 | 自动 |
| 用户主动导出 | 一键导出全空间 JSON（含媒体 fileId 清单） | 手动 |
| 定时导出（可选） | 云函数定时任务生成快照（占用配额，默认关闭，需用户开启） | 可选【需核实触发配额】 |

# 3. 软删除与回收站

- 所有业务删除用 `deleted=true` 软删除。
- 保留期：菜谱 30 天、饮食计划/购物清单 15 天、库存流水/关键操作日志长期保留（按需清理）。
- 回收站页面列出可恢复项；超过保留期由云函数定时清理（标记后删除图片）。

# 4. 导出格式

- 导出自定义 JSON：包含 schemaVersion、exportedAt、workspaceId、各集合数组、media 文件清单。
- media 采用 `media_assets` 的 fileId 引用，不内嵌二进制；导入时可引导重新上传或跳过图片（保留占位）。

# 5. 导入恢复

`backup.import` 云函数：
1. 校验 JSON 的 `schemaVersion` 与当前版本兼容。
2. 校验导出 workspaceId 与导入目标一致（或提供“迁移到新空间”选项，需显式确认）。
3. 幂等写入（主键冲突跳过并记录），逐集合恢复。
4. 输出恢复报告：成功/跳过/失败数量。

# 6. 权限与安全

- 仅空间 Owner（家庭）或本人（个人）可导出/导入。
- 导出含数据，导入必须校验权限并写 operation_logs。
- 备份 JSON 不落公共存储，可通过云存储私有目录或临时链接交付。

# 7. 异常与验收

- 导入中断可重试（幂等），不产生重复主键。
- 恢复后业务正常（列表、详情、排行正确）。
- 验收用例见 docs/TEST_PLAN.md 的备份恢复组。

# 8. 待联网核实

- 云函数定时触发器在免费额度下的配额与限制（若不达标则仅保留手动导出）。
