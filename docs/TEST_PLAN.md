# 食记 Kitchen 测试计划

核对日期：2026-11-20

# 1. 测试分层

| 层 | 工具/方式 | 覆盖 |
| --- | --- | --- |
| 单元测试 | Jest / Vitest | 纯函数：单位换算、份量缩放、营养计算、成本计算、余额/批次 FIFO、日期/排行榜聚合 |
| 云函数测试 | Jest + mongodb-memory 或 mock wx-server-sdk | 权限校验、邀请码、库存流水、购物清单聚合、备份导入 |
| 集成测试 | 微信开发者工具 + CloudBase 测试环境 | 登录、写库、watch 同步、图片上传鉴权 |
| UI/端到端 | 微信开发者工具 + 真机 | 页面流程、异常提示、回归 |
| 手工验收 | 按 PRD 验收标准 | 各功能模块 |

# 2. 纯函数测试重点

- 份量缩放：4→2、2→8、目标=1、含不可小数单位。
- 单位换算：克/千克、毫升/升、可换算与不可换算分支。
- 营养/成本聚合：缺失数据、均价/最近价、单位不一致。
- 库存 FIFO：多批次扣减、扣超报错、报损。
- 排行聚合：周/月/年、软删除排除、重复统计去重。

# 3. 云函数测试重点（安全优先）

- 越权矩阵：非成员跨空间读写均应 403。
- 角色边界：Member 改角色/移除成员被拒。
- 邀请码：一次性、过期、撤销、并发 accept 只成功一次、满员拒绝。
- 被移除成员：旧 token 无效。
- 图片：无权限 fileId 拿不到链接。
- 伪造 openid/workspaceId 无效。

# 4. 同步测试重点

- 写库后其他在线端 watch 收到（以核实后的能力为准）。
- 断网写→重连→增量对账正确，无重复主键。
- watch 关闭与重连行为。
- 并发冲突按版本“后写覆盖”。

# 5. 端到端用例（按模块）

| 模块 | 关键用例 |
| --- | --- |
| 菜谱 | 创建/编辑/软删除/恢复/收藏/分类筛选/复制到家庭 |
| 食材 | 字典增改合并/菜谱引用不受删除影响 |
| 份量/成本/营养 | 缩放、成本累加、营养汇总、缺失处理 |
| 饮食计划/点菜 | 按天餐次、点菜采纳、一键生成清单 |
| 购物清单 | 聚合去重、勾选同步 |
| 库存 | 采购入库、FIFO 扣减、报损、临期提醒 |
| 记录/相册/日历/排行 | 记录上传、日历聚合、排行统计 |
| 备份 | 导出→导入→恢复一致、schema 校验、幂等重试 |

# 6. 环境与数据

- 开发/测试/正式环境分离（至少开发与正式）。
- 测试数据含临期、过期、并发场景。
- 支持“测试日期”注入以便验证时间相关逻辑（临期、排行周期）。

# 7. 回归与发布门禁

- 每阶段结束：相关单元测试全绿 + 该阶段验收用例通过。
- 提测前：静态检查（TS、lint）、安全用例、密钥扫描。
- 正式发布前：完整回归 + 真机 + 隐私合规检查。

# 8. 报告

- 每次执行输出：通过/失败用例数、失败原因、覆盖模块。
- 禁止伪造结果；无法运行的环境（如未安装微信开发者工具）明确记录。
