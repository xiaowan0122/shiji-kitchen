核对日期：2026-11-20

# 1. 免费环境资格与额度（待核实）

需在腾讯云 CloudBase 控制台/官方文档核实：
- 免费环境（Free plan / 开发者套餐）的准入条件与地域。
- 免费数据库存储容量（估算量级：GB 级，具体以文档为准）。
- 免费云存储容量。
- 免费 CDN 流量（传统/边缘加速额度）。
- 免费云函数调用次数与资源使用量（如每月调用次数、GBs、外网流量）。
- 免费环境下实时监听连接的额度与超限处理。
- 免费环境是否自动到期、如何升级，以及到期后数据是否受影响。
- 微信小程序体验版与正式版对 CloudBase 环境的使用限制（是否必须绑定 AppID、是否需要完成审核等）。

> 免费政策可能变化，禁止把任一数字写成“永久/固定”。

# 2. 用量估算（本产品场景）

场景假设：1 个个人空间 + 1 个家庭空间，3～5 名成员，日常使用。

| 项目 | 估算 | 说明（估算，非保证） |
| --- | --- | --- |
| 数据库文档数 | 数百～数千 | 菜谱、食材、计划、清单、批次、记录 |
| 每用户月读次数 | 数千～数万 | 列表/详情/同步对账 |
| 每用户月写次数 | 数百～数千 | 增删改 |
| 云函数调用 | 每月数千～数万 | 业务写、聚合、登录 |
| 图片存储 | 数十～数百张 | 菜谱图/相册，每张压缩后 ≤ 500KB |
| CDN/读流量 | 低 | 家庭场景，列表用缩略图 |
| 实时连接 | 数百～数千次短线连接 | 取决于进入页面的 watch 行为 |

结论方向：按 3～5 人家庭 + 个人，正常使用**有望**落在免费额度内，但**必须用真实测试验证**，否则需优化（缩略图、减少轮询、合并请求）。

# 3. 成本控制手段

1. 客户端压缩图片、用缩略图，控制存储与流量。
2. 优先 watch 替代高频轮询，降低读次数。
3. 列表分页、精确字段查询，避免全集合拉取。
4. 聚合（排行/营养/成本/购物清单）放云函数，减少客户端重复读。
5. 单云环境、函数按域合并，减少冷启动与函数数量。
6. V1.0 不接付费 AI，避免 token 费用。

# 4. 预算结论

- 目标 0 元：在联网核实免费额度后，以“压缩 + watch + 云函数聚合 + 缩略图”策略，大概率处于免费范围；未核实前不承诺。
- 若超免费额度，第一优先级是优化与降级（轮询转事件、更小缩略图），而非购买套餐。
